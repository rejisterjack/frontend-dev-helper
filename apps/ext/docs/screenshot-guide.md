# Screenshot Guide for Chrome Web Store

## Requirements
- Format: PNG or JPEG
- Dimensions: 1280x800 (recommended) or 640x400
- Minimum: 1 screenshot, Maximum: 5 screenshots
- No text overlay covering more than 30% of image

## Screenshot Plan (5 screenshots, 1280x800)

### Screenshot 1: Dashboard Overview
**Purpose:** Show the breadth of tools available
**Setup:**
- Open the FDH DevTools panel on a modern website (e.g., github.com, vercel.com)
- Ensure the Dashboard view is showing with all 6 tool categories visible
- Dark theme enabled
- Connection status badge showing "Connected"
- Category icons with active tool counts visible

**What to capture:**
- Full DevTools panel with sidebar navigation
- Dashboard cards for each category (Inspection, CSS, Performance, Accessibility, AI, Utility)
- Active tools badge in header

### Screenshot 2: DOM Outliner on Real Website
**Purpose:** Show visual overlay capabilities
**Setup:**
- Activate the DOM Outliner tool on a real website
- Choose a page with diverse element types (nav, sections, cards, footer)
- Use default outline colors
- Ensure outline labels are visible

**What to capture:**
- Browser viewport with colorful DOM outlines overlaid
- FDH panel showing the tool config
- Element labels with depth indicators

### Screenshot 3: Accessibility Audit Results
**Purpose:** Demonstrate compliance checking
**Setup:**
- Run a Full Audit on a page with known accessibility issues
- Show the audit results panel with score ring
- Ensure category scores and issue list are visible
- Show severity badges (critical, serious, moderate)

**What to capture:**
- Audit panel with overall score (e.g., 72/100)
- Category breakdown: Accessibility, Performance, SEO, Best Practices
- Issue list with severity indicators

### Screenshot 4: AI Chat Analyzing a Page
**Purpose:** Show AI-powered analysis
**Setup:**
- Open the AI Chat panel
- Have a conversation about page issues
- Show AI response with actionable suggestions
- Dark theme

**What to capture:**
- AI chat interface with message history
- AI response containing code suggestions
- Connection indicator showing AI is configured

### Screenshot 5: Export & Multi-Format
**Purpose:** Show export capabilities
**Setup:**
- Run a Full Audit
- Show the export dialog or export buttons
- Display multiple format options (JSON, HTML, Markdown, cURL)
- Could show a portion of the exported HTML report

**What to capture:**
- Export panel with format options
- Preview of exported content
- Or: Network Replay panel showing cURL export option

## Tips
- Use consistent dark theme across all screenshots
- Ensure text is readable at 1280x800
- Avoid showing sensitive/personal data in screenshots
- Use well-known, publicly accessible websites
- Show real, meaningful content rather than placeholder data
